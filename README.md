# Energy Mix Application

Full-stack application built for a recruitment task.  
Live demo: https://clean-energy-frontend-a1kw.onrender.com  
_Note: Initial request may be slow as the backend spins up from an idle state._

## Overview
- Backend API - Spring Boot, available at https://github.com/Gleb932/clean-energy-backend
- Frontend - React, TypeScript

## Architecture
Frontend → Backend API → External API

## Features
- Fetches energy data from external source
- Calculates the cleanest window for charging
- Aggregates data for several days
- Includes unit tests for core backend logic
